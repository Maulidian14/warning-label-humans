Entry for the [make.fun bounty "Warning Label for Humans: One Line, Big Laugh"](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85).

`main.ts` writes a single warning label for humans (111 characters) to `/output/entry.txt`:

> WARNING: This human will nod, smile, and agree to plans it has no intention of keeping. Do not rely on the nod.

Run it with `node main.ts`. The output path is resolved relative to the script's own directory when `/output` is unavailable, so the entry works from any working directory.
